# 雅思口语母题分类与素材适配设计

## 目标

在现有 Vite 原生 JavaScript 应用中，以增量方式补齐 Part 2 题库分类入口，并将题库、八份核心素材、题目适配答案和练习复盘串成完整流程。保留现有页面布局、录音、转写、朗读和复盘主逻辑，不迁移 Next.js、TypeScript 或 Zustand。

产品的核心约束是减少准备压力：题目先归入八个固定母题或未分类池；八个母题各准备且仅准备一份核心素材；未分类题可以准备一份题目专属素材；选题后系统自动使用唯一确定的素材生成适配答案。

## 母题常量

内部统一使用 `M1` 至 `M8`，界面只显示自然名称，不显示内部 ID。

| ID | 显示名称 | 旧 ID |
| --- | --- | --- |
| M1 | 人物－长辈 | elder-person |
| M2 | 人物－同辈 | peer-person |
| M3 | 物品－旧物 | old-object |
| M4 | 物品－虚拟技能 | virtual-object |
| M5 | 地点－自然 | nature-place |
| M6 | 地点－室内 | indoor-place |
| M7 | 经历－成功 | success-experience |
| M8 | 经历－挫折 | setback-experience |

每个常量还包含中英文描述和本地分类关键词。读取旧 LocalStorage 时将旧 ID 映射为新 `motherId`；旧字段暂时保留，不重命名或删除。

## 数据模型

### 季度

```js
{
  id: '2026-05-08',
  label: '2026 年 5–8 月',
  status: 'current',
  createdAt: '...'
}
```

`status` 可以是 `current`、`upcoming` 或 `archived`。季度选择只改变当前展示和练习选题，不删除历史季度。

### 题目

```js
{
  id: '...',
  prompt: '...',
  cues: [],
  tags: [],
  seasonId: '2026-05-08',
  motherId: 'M1',
  source: 'official',
  normalizedPrompt: '...',
  createdAt: '...'
}
```

`motherId` 为 `null` 时表示未分类。`source` 为 `official` 或 `user`。字段只扩展，不修改已有字段名称。

同一道题跨季度出现时保留为两个季度记录，各自拥有独立 `id` 和 `seasonId`。系统根据规范化题干识别重复题，并为新季度记录继承最近历史记录的 `motherId`。之后在某季度手动调整分类，只修改该季度记录。

### 素材

母题核心素材：

```js
{
  id: '...',
  motherId: 'M1',
  title: '和爷爷去湖边钓鱼',
  story: '...',
  type: 'mother-core'
}
```

未分类题专属素材：

```js
{
  id: '...',
  questionId: '...',
  seasonId: '2026-09-12',
  title: '...',
  story: '...',
  type: 'question-specific'
}
```

每个母题最多一份核心素材，每道未分类题最多一份专属素材。核心素材可以编辑或替换。已有且没有新字段的旧素材继续可读，不强制迁移为核心素材。

题目从未分类池进入母题后，自动改用该母题核心素材。题目从母题移回未分类池后，如果没有专属素材，界面提示用户准备。

### 保存的适配答案

```js
{
  questionId: '...',
  seasonId: '2026-09-12',
  materialId: '...',
  materialUpdatedAt: '...',
  content: '...',
  updatedAt: '...'
}
```

每道题只保存一份当前答案。AI 生成后进入可编辑状态，用户点击“保存答案”才覆盖当前保存版本。覆盖前需要确认。重新打开题目时优先显示已保存答案。

如果素材在答案保存后发生修改，旧答案继续保留，并提示素材已经更新、可以重新生成。

## 数据来源与持久化

版本内置题库存放在静态数据文件中，作为只读官方基础数据。用户补充题、分类覆盖、季度选择、素材和适配答案存入 LocalStorage。页面加载时合并官方基础数据、用户补充数据和用户覆盖数据。

存储数据带 schema 版本。迁移过程保留旧 LocalStorage key 和旧字段，不自动删除原数据。解析或迁移失败时以可恢复的空新状态启动，并在控制台记录错误。

官方题库随版本更新时只合并新增题目，不覆盖用户的手动分类、素材或保存答案。

## 季度题库与补充题导入

题库页顶部增加季度选择器，默认最近季度。页面只展示当前季度题目，并标注官方题或个人补充题。

“导入补充题”弹窗流程：

1. 选择目标季度。
2. 粘贴多道 Part 2 题目，以空行或编号边界解析。
3. 展示解析预览。
4. 同季度按规范化题干去重，重复记录跳过。
5. 跨季度重复题创建新季度记录并继承已有分类。
6. 其余新增题进入 DeepSeek 初筛。
7. 初筛完成后进入分类确认界面。
8. 用户点击“确认分类”后才写入正式 LocalStorage。

导入新题不会清空旧季度或当前季度已有题目。

## 分类弹窗

弹窗左栏显示八个母题及数量徽章，右栏显示当前母题的题目卡片，底部固定显示未分类池。卡片只显示必要的题干、来源和季度信息，不显示匹配百分比。

分类在弹窗草稿中操作。用户可以在母题之间拖拽、拖入未分类池或从未分类池拖回母题。现有原生拖拽继续使用，并补充 Pointer Events 以支持触屏；不引入依赖 React 的 `@dnd-kit`。

关闭存在未确认修改的弹窗时二次确认。点击“确认分类”才持久化本轮全部 `motherId`。允许确认时仍有未分类题，但明确提示数量。

## DeepSeek 初筛与本地降级

DeepSeek 使用 JSON Output 批量返回 `questionId` 和 `motherId`，不返回或展示百分比。已有跨季度继承结果的题目不调用 AI。

若 API 密钥缺失、请求失败、响应结构错误或部分题目遗漏，只对未完成题目执行本地分类。本地分类结合母题中英文关键词、题干规范化和字符串相似度；无法可靠判断时返回 `null`，将题目放入未分类池。

界面只提示“已完成初步分类”以及本次使用 AI 或本地初筛，不把结果描述为客观语义相似度。AI 和本地算法都只提供初筛，最终归类由用户确认。

## 核心素材与专属素材界面

素材库显示八个固定核心素材位，每个位置对应一个母题。空位提供“准备素材”入口，已有素材提供编辑或替换入口。界面只显示“人物－长辈”等名称。

未分类题在选题或题库卡片中提供专属素材入口。素材编辑器保留现有布局和字段，只增加素材类型及绑定信息。已有素材页面和核心生成逻辑不重构。

## 选题与答案适配

选中已归类题时，系统自动使用该母题唯一核心素材。选中未分类题时，系统自动使用该题唯一专属素材。不存在相应素材时允许查看题目，但生成答案前引导用户准备素材。

练习页只增加一行简洁上下文，例如：

```text
人物－长辈
使用素材：和爷爷去湖边钓鱼
```

AI 适配请求包含题干、cue points、母题自然名称和素材正文。AI 必须保留用户事实，不虚构具体信息，并生成三个自然段：

1. 开头段自然复述题意并引入素材。
2. 中间段根据题干和 cue points 选择、突出素材中相关细节。
3. 结尾段回应感受、影响或总结。

输出继续放在现有答案区域，不新增复杂分栏。生成结果可以编辑并保存。再次生成已有保存答案时，覆盖前确认。

## 素材复用高亮

复习已保存答案时，前端对原始素材与适配答案做确定性英文短语匹配。连续重复的关键短语或句段使用柔和底色高亮，点击或悬停提示“来自核心素材”或“来自本题素材”。冠词、连接词、常见短语和过短片段不单独高亮，避免噪声。

高亮是派生视图，不写入答案正文。复制和编辑得到纯文本；编辑后重新计算高亮。匹配实现必须处理大小写、标点和空白差异，并避免相互重叠的标记。

## 练习与复盘

现有朗读、录音、转写和复盘流程保持不变。复盘请求增加题目母题和原始素材上下文。

AI 比较用户转写与原始素材：合理复用事实和关键词不提示；只有连续长片段、句序或大量措辞高度一致时，才委婉建议调整连接词、句子顺序或表达方式。不显示机械重复率。没有素材或转写过短时跳过模板化判断。

DeepSeek 复盘失败不影响本地录音、转写或回放。

## 错误处理

- LocalStorage 损坏：不删除旧 key，以空的新状态启动并记录错误。
- DeepSeek 不可用：题库初筛自动降级到本地；答案适配显示可重试错误。
- 批量初筛部分失败：保留成功结果，其余使用本地算法或进入未分类池。
- 未准备素材：允许浏览题目，但在生成前提供准备入口。
- 季度官方数据更新：只合并新增题，不覆盖用户数据。
- 未确认分类弹窗关闭：二次确认后放弃草稿。

## 实施阶段与提交边界

1. 数据基础：母题常量、季度与存储模型、兼容迁移、纯函数测试。
2. 题库分类器：季度选择、粘贴导入、去重、分类弹窗、拖拽、确认持久化。
3. 智能初筛：DeepSeek 批量分类、本地降级和部分失败处理。
4. 素材体系：八个核心素材位、未分类题专属素材和唯一性约束。
5. 答案适配：自动选取唯一素材、三段式生成、编辑与一题一份保存答案。
6. 复习与复盘：复用片段高亮、素材版本提示和模板化表达反馈。

各阶段分别提交。任何阶段都不重构功能 2、3、4 的现有页面布局或核心逻辑。

## 验收标准

- 刷新后季度、补充题、分类、素材和保存答案不丢失。
- 同题跨季度建立独立记录并继承分类；同季度重复导入不产生副本。
- 拖拽后取消不落库，点击“确认分类”后才持久化。
- 每个母题无法创建第二份核心素材，每道未分类题无法创建第二份专属素材。
- 归类题自动使用母题核心素材，未分类题自动使用题目专属素材。
- 未配置 DeepSeek Key 时仍能完成本地题库初筛。
- AI 生成三个自然段，不虚构素材事实；答案可编辑、保存和重新打开。
- 每道题只保留一份当前答案，重新生成覆盖前需要确认。
- 复习视图准确高亮素材复用片段，复制内容不包含高亮标记。
- 素材更新后旧答案保留并显示更新提示。
- 现有朗读、录音、转写和复盘流程通过回归验证。
